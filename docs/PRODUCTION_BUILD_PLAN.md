# Production Build Plan

## เป้าหมาย
คอมไพล์โค้ด ERP ทั้งหมด (Phase 1 & Phase 2) ให้เป็นเวอร์ชัน Production เพื่อแก้ปัญหาหน่วง/อืด และให้ระบบทำงานได้เร็วที่สุด

## ขั้นตอนการดำเนินการ
1. **ตรวจสอบความเรียบร้อย:** รัน Typecheck และ Lint ให้แน่ใจว่าไม่มี Error ค้างอยู่
2. **ปรับแต่ง (Optimize):** เพิ่มคำสั่งปิดโหมด Debug ที่กินทรัพยากร
3. **Build:** รันคำสั่ง `npm run build` เพื่อให้ Next.js ทำการบีบอัดโค้ด สร้างหน้าเว็บล่วงหน้า (SSG/ISR) และเตรียมไฟล์สำหรับรันจริง
4. **Start Production Server:** ปิด Dev Server เดิมที่รันอยู่ (พอร์ต 3001) และสั่งรัน `npm run start` เพื่อเปิดเซิร์ฟเวอร์แบบ Production ขึ้นมาแทนที่พอร์ต 3001
5. **ทดสอบ:** เข้าใช้งานผ่านเบราว์เซอร์เพื่อดูความเร็วที่เพิ่มขึ้น
